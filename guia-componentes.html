🧠 Concepto Clave de Repaso: ¿Qué es HTML Semántico?

En lugar de usar etiquetas genéricas <div> para todo, el HTML5 semántico utiliza etiquetas con significado específico: <header> indica encabezado, <nav> barra de enlaces, <main> el contenido principal, <section> un bloque temático y <footer> el pie de página. Esto beneficia la accesibilidad, lectores de pantalla y el posicionamiento SEO en Google.

🎯 ¿Cuál es su función?

  • Fijación Permanente: Permanece visible arriba al hacer scroll gracias a fixed top-0.
  • Identidad DEVFUSION: El logo con degradado azul marino y texto en negrita.
  • Enlaces de Salto Interno: Al pulsar "ABOUT", salta con animación suave a #about.
  • Selector de Idioma: Desplegable con banderas para alternar entre Español, Inglés y Francés.

⚡ Lógica JavaScript & Tailwind

  • backdrop-blur-md: Crea el efecto de vidrio esmerilado que difumina el contenido detrás.
  • bg-[#060b19]/85: Fondo azul noche con 85% de opacidad para dar profundidad.
  • Scroll Spy: JavaScript detecta en qué sección estás y resalta el enlace activo con una línea azul.
  • data-i18n: Atributo que traduce automáticamente el menú al cambiar de idioma.
💡 Pregunta de Auto-Estudio #1

¿Por qué el <header> utiliza z-50? Porque el "Z-Index" determina qué elemento queda por encima de los demás; con 50 garantizamos que el menú nunca quede tapado por las imágenes o textos al hacer scroll.

🍱 ¿Por qué se llama "Bento Grid"?

Inspirado en las cajas de comida japonesas Bento con compartimentos de distintos tamaños, Apple y las grandes empresas tecnológicas popularizaron este diseño para mostrar características sin aburridas listas verticales:

  • Asimetría Visual: Tarjeta principal ancha (md:col-span-7) combinada con tarjetas medianas (md:col-span-5 y col-span-4).
  • Jerarquía: El Stack MERN destaca como protagonista.

🧩 Las 5 Cajas del Bento Grid

  • 1. Core Stack MERN: React, Next.js, TypeScript, Node.js, Express, MongoDB, Tailwind.
  • 2. Rendimiento: Puntuación Lighthouse 95+ y 100% diseño responsivo.
  • 3. Bases de Datos & Cloud: PostgreSQL, MongoDB, AWS, Firebase.
  • 4. Calidad & Prácticas: Git, pruebas unitarias con Jest, Docker y CI/CD.
  • 5. UI/UX & Frontend: Tailwind, Redux, GraphQL y Micro-animaciones.

🚀 Los 4 Comportamientos Dinámicos de JavaScript

  • 1. Scroll Spy: window.addEventListener('scroll') calcula la posición en tiempo real e ilumina el menú superior.
  • 2. Botón Volver Arriba: Botón flotante redondo azul que aparece cuando bajas más de 400px.
  • 3. Sistema i18n Trilingüe: Diccionario de traducción instantánea en Español, Inglés y Francés.
  • 4. Copiar Email: Usa la API navigator.clipboard.writeText con confirmación visual.
